# jacksoncool69.github.io
<h1>Splitbot</h1>
<p>Splitbot is a personal tool used only by its owner, Jackson. It reads, with read-only access, Frollo export emails in the owner's own Gmail and saves their CSV attachment on the owner's own computer. No data is shared with, sold to, or sent to anyone else. Access can be removed at any time at myaccount.google.com/permissions.</p>
